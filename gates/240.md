# #240：打印管线最小闭环（2026-11-06，R5 后续·P1 / #229 缺口分级唯一「缺失」级）

**背景**：Acrobat parity 12 面普查（#229，`docs/pdf-acrobat-parity.md`）打印 =
0% 覆盖——高频验收面（打开/渲染/表单/签名/标注/打印）唯一完全缺失项。
用户 1.0 目标「1比1不降级甚至在性能这块超越他」（对标 Acrobat）。
排期：Lead 派单（#240 评论，用户裁定打印排期 P1）。

**侦察实证（实施前，步骤 1 结论——按 issue 纪律先查再定路线）**：
① GPUI **无打印 API**：third_party/zed 全域检索 print 命中全部是 IME
printable-keys 语义（platform.rs/keystroke.rs），无 PrintOperation/NSPrint/
StartDoc 封装——方案 B（GPUI 打印封装）不存在；② mdc-pdf `Rasterizer`
（render.rs）渲染能力齐全（BGRA 位图 + S3-L2 钳制），但注释渲染位硬编码
`render_annotations(true)`（S2-3 阅读面契约）、无 DPI 口径/页区间编排；
③ mang-shell PDF 视 = 文本抽取态（pdf_doc.rs），无图形渲染面；④ web 打印态
`@media print` 把 `#pdf-panel` 藏掉（打印的是编辑器正文）；⑤ 全仓零打印
命令/菜单。**路线裁决 = 引擎原语 + 壳方案 C + web 打印专用视图**（Lead 倾向
方案 C，经侦察证实成立——系统对话框免费承载页区间/份数/缩放）。

**实现（三层，分层落地）**：
- **引擎面**（`crates/pdf/src/print.rs` 新模块 + `render.rs`/`engine_pdfium.rs`
  增量）：`PrintSpec{dpi, annotations}`（DPI 域 [36,2400] 钳制收敛——S3-L2
  同哲学，生效尺寸以 RenderedPage 报告为准）+ `PageSelection`（All/闭区间，
  typed 越界拒绝）+ `dpi_width_px`（72pt 基准 × DPI/72）+ `render_for_print`
  （`DocumentEngine + Rasterizer` 双约束泛型编排——几何取 effective_width
  旋转归一）。注释开关接线：`Rasterizer::rasterize_with_options` trait 默认
  方法（默认忽略 = 阅读面 S2-3 契约零波及，mock 零成本兼容）+ Box 转发 +
  `PdfiumEngine` 覆写真接线（rasterize_impl 共体重构，`FPDF_ANNOT` 位透传）。
  阅读面（预览/工人/OCR）继续走 `rasterize` 不经新面。
- **壳面**（`mang-shell/src/print.rs` 新模块 + menu_bar/shell 接线）：方案 C
  系统打印流——Windows `powershell Start-Process -Verb Print`（系统打印
  对话框承载设置面）/ macOS `open -p` / Linux CUPS `lp`（设置映射参数：
  `-P` 页区间 1 基直通 / `-n` 份数 / `-o fit-to-page` 缩放）。可测性纪律：
  参数构造全拆纯函数（`lp_args`/`windows_args`/`macos_args` 单测逐字锁）；
  exec 层只留存在性校验 + 启动 + 退出码；typed 错误（NotFound/NoBackend/
  Spawn）。UI：文件菜单「打印…」（`MenuContext.is_pdf` 门槛灰显）→
  `ShellApp::print_active_document`（非 PDF 给可操作提示，无文档不崩溃）。
- **web 面**（`web/index.html` + `pdf_view.ts` + i18n×2）：**打印专用视图**——
  工具栏「打印」钮 + Ctrl/Cmd+P 拦截（仅 PDF 面板激活时接管，编辑器态
  Ctrl+P 行为不变）→ `printDocument()`：逐页 150dpi 渲染（PRINT_SCALE =
  150/72，与引擎 PrintSpec 同口径；pdf.js 同一渲染管线 = **打印输出与屏幕
  渲染同源**）→ canvas → PNG blob（位图内存即用即释；远页不受屏幕虚拟化
  clearFarCanvases 波及——打印容器独立）→ 隐藏 `#pdf-print-container`
  （`body.printing-pdf` 打印态显示、每页 break-after: page）→ `window.print()`
  系统对话框（页码/份数/缩放承载）。afterprint 清理 + 重入残留清理。

**测试证据**：
- 引擎单测（默认面，CI 裸环境可跑）：print.rs 10 用例——DPI 换算锚
  （Letter 612pt@150dpi→1275px / A4@300dpi→2479px / 72dpi=1:1）、域钳制、
  区间展开（All/闭区间/翻转拒/越界拒 typed InvalidPage）、编排转发
  （页序/宽换算/注释位透传/位图合同）、trait 缺省兼容锚
  （reading_only_rasterizer_still_serves_print——只实装 rasterize 的既有
  Rasterizer 经打印入口仍可用）；
- parity 打印面（pdfium 门，`pdfm_acrobat_parity.rs`
  `parity_print_render_dpi_range_annotations`）：真实 pdfium 三合一——150dpi
  换算（1275×1650 位图合同）+ 区间 [1,2]→2 页 + 注释开关红墨迹翻转
  （LopdfWriter 写三条粗红 Ink → `render_annotations:true` 红占比显著上升
  （>0.02 增量，与 pdff3 锁 4 同像素口径）/ `false` 回落基线（<0.005 差））；
- 壳单测（mang-shell lib）：print.rs 7 用例——lp 参数三态（缺省/全设置/
  单页区间）+ 规整（翻转交换/份数下限）+ 平台参数形状 + NotFound typed
  路径 + describe 凭据；menu_bar 布局锁 3 处随新条目更新（索引/行偏移/
  漂移自愈——漂移测试改双向一致性断言，不预设关闭）；

  **269 过 0 挂**（含既有渲染语义锁 pdff3 全绿——阅读面零回归）；
  主 workspace（--exclude mdshell-native）**1427 过 0 挂**；mang-shell lib
  **464 过 0 挂**；wasm32 双出口（mdcore-wasm / mdc-pdf-wasm）check 绿；

  （parity #9 行登记为「部分」）。
